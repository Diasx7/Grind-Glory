# Grind & Glory

App web gamificado onde suas tarefas da vida real viram XP e evoluem um herói de RPG.

Esse é o **Dia 1** do projeto: só o setup e a tela inicial. Ainda não tem
lista de tarefas, herói ou batalha — isso vem nos próximos dias.

## Stack

- React
- Vite
- (sem banco de dados ainda, isso é pra depois)

## Como rodar local

```bash
npm install
npm run dev
```

Depois é só abrir o link que aparece no terminal (geralmente
`http://localhost:5173`).

## Deploy

Projeto pronto pra subir na [Vercel](https://vercel.com), sem configuração
extra (ela já reconhece projeto Vite sozinha).
